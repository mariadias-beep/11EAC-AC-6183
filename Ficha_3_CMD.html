Comandos básicos do Windows – Modo Texto (CMD)

EPG - Professora Maria DiasWindowsLinha de Comandos90 minutos
Objetivos de aprendizagem
  • Abrir e utilizar a Linha de Comandos (CMD).
  • Navegar entre diretórios e consultar o seu conteúdo.
  • Criar pastas e ficheiros.
  • Copiar, mover, renomear e eliminar ficheiros e pastas.
  • Utilizar comandos básicos do Windows em modo texto.

1. Conhecer os comandos

Consulta a tabela antes de iniciares as tarefas.

ComandoFunção
dirLista ficheiros e pastas do diretório atual.
cdMostra ou altera o diretório atual.
cd ..Volta à pasta anterior (pasta acima).
cd \Vai para a raiz da unidade atual.
mkdir / mdCria uma pasta.
echoEscreve texto; com > permite criar um ficheiro.
typeMostra o conteúdo de um ficheiro de texto.
copyCopia ficheiros.
moveMove ficheiros ou pastas.
renAltera o nome de um ficheiro ou pasta.
delElimina ficheiros.
rmdirElimina uma pasta vazia.
clsLimpa o ecrã da Linha de Comandos.

2. Preparação do exercício

  1. Abre o menu Iniciar do Windows.
  2. Escreve cmd e abre a aplicação Linha de Comandos.
  3. Cria a pasta de trabalho e entra nela:
mkdir C:\Exercicio_CMD
cd C:\Exercicio_CMD
Estás agora dentro da tua pasta de trabalho. Realiza as tarefas seguintes nesta pasta, salvo indicação em contrário.

3. Parte prática – Vamos trabalhar!

Tarefa 1 – Criar pastas

Cria a seguinte estrutura dentro de C:\Exercicio_CMD:

Exercicio_CMD ├── Documentos ├── Imagens └── Backup
mkdir Documentos
mkdir Imagens
mkdir Backup
dir

Tarefa 2 – Navegar entre pastas

Executa os comandos, um de cada vez:

cd Documentos
cd
cd ..
cd Imagens
cd ..

Tarefa 3 – Criar ficheiros

Entra na pasta Documentos e cria três ficheiros:

cd Documentos
echo O meu primeiro ficheiro > trabalho.txt
echo Este e um exercicio de Windows > notas.txt
echo Sistemas Operativos > disciplina.txt
dir
type trabalho.txt

Tarefa 4 – Copiar ficheiros

Regressa à pasta principal, copia o ficheiro e confirma:

cd ..
copy Documentos\trabalho.txt Backup
dir Backup

Tarefa 5 – Mover ficheiros

Move o ficheiro notas.txt de Documentos para Imagens:

move Documentos\notas.txt Imagens
dir Documentos
dir Imagens

Tarefa 6 – Alterar o nome de um ficheiro

Altera o nome de disciplina.txt para informatica.txt e confirma:

ren Documentos\disciplina.txt informatica.txt
dir Documentos

Tarefa 7 – Eliminar ficheiros e pastas

Elimina a cópia de segurança, cria uma pasta temporária e elimina-a:

del Backup\trabalho.txt
dir Backup
mkdir Temporaria
rmdir Temporaria
dir
Atenção! Antes de utilizares del ou rmdir, confirma sempre o caminho. Estes comandos podem eliminar dados sem os colocar na Reciclagem. O comando rmdir, sem opções adicionais, elimina apenas pastas vazias.

4. Desafio final – Faz sozinho!

Situação: Uma empresa pediu-te para organizares os ficheiros de um novo funcionário. Realiza as operações sem consultares os exemplos anteriores.

Funcionario ├── Pessoal │ ├── dados.txt │ └── contacto.txt ├── Trabalho │ └── tarefas.txt └── Copias
  1. Criar a pasta Funcionario e entrar nela.
  2. Criar as subpastas Pessoal, Trabalho e Copias.
  3. Criar dados.txt e contacto.txt dentro de Pessoal.
  4. Criar tarefas.txt dentro de Trabalho.
  5. Escrever uma frase em cada ficheiro.
  6. Copiar dados.txt para Copias.
  7. Mover contacto.txt para Trabalho.
  8. Renomear tarefas.txt para tarefas_2026.txt.
  9. Apresentar a estrutura final com tree /f.
