Sistemas Operativos

Conceitos, hardware, linha de comandos, ambiente gráfico, administração, instalação, configuração e segurança.

🎯 Objetivo
Compreender e utilizar um sistema operativo de forma segura.
🧪 Metodologia
Aprender → observar → executar → testar → resolver.
🛠️ Prática
As tarefas podem ser realizadas numa máquina virtual ou num computador de laboratório.

1. Introdução aos sistemas operativos

Um sistema operativo (SO) é o software fundamental que gere os recursos de um computador e permite ao utilizador executar aplicações.

⚙️ Gestão de hardware

Controla CPU, memória, armazenamento e periféricos.

📁 Gestão de ficheiros

Organiza ficheiros, pastas e dispositivos de armazenamento.

👤 Gestão de utilizadores

Controla contas, sessões, grupos e permissões.

🛡️ Segurança

Ajuda a proteger dados, contas e recursos do sistema.

Exemplos

  • Windows — computadores pessoais e profissionais.
  • Linux — servidores, computadores e dispositivos.
  • macOS — computadores Apple.
  • Android — smartphones e tablets.
📝 Tarefa 1 — Identificar funções de um SO

Enunciado: Indica quatro funções de um sistema operativo e apresenta dois exemplos de sistemas operativos.

Resolução exemplo: Gestão do hardware, gestão de ficheiros, gestão de utilizadores e gestão de processos. Exemplos: Windows e Linux.

2. O sistema operativo e o hardware

O SO funciona como uma camada de ligação entre as aplicações/utilizador e o hardware.

👤 Utilizador → 🖥️ Aplicações → ⚙️ Sistema Operativo → 🔧 Hardware
ComponenteFunçãoInteração com o SO
CPUExecuta instruçõesO SO distribui tempo de processamento
RAMArmazena dados temporáriosO SO gere a memória utilizada pelos programas
Disco/SSDArmazena dadosO SO gere ficheiros e partições
GPUProcessa gráficosÉ utilizada através de drivers
PeriféricosEntrada/saídaSão controlados através de drivers
📝 Tarefa 2 — Hardware e software

Enunciado: Um aluno abre um editor de texto e escreve uma frase. Identifica pelo menos quatro componentes de hardware envolvidos.

Resolução exemplo: CPU processa instruções; RAM mantém o programa e dados em utilização; teclado fornece entrada; monitor apresenta a informação; SSD pode armazenar o ficheiro.

3. Tipos de sistemas operativos

Um sistema pode ser classificado de acordo com o número de utilizadores, tarefas, dispositivos e outras características.

TipoDescriçãoExemplo
MonoutilizadorOrientado para utilização por um utilizador de cada vez.Alguns sistemas pessoais/ambientes específicos
MultiutilizadorPermite vários utilizadores com contas e permissões diferentes.Linux/Unix e sistemas de servidor

Sessão: período durante o qual um utilizador está autenticado e utiliza os recursos do sistema.

📝 Tarefa 3 — Contas e sessões

Enunciado: Explica a diferença entre utilizador e sessão.

Resolução: O utilizador é uma identidade/conta com credenciais e permissões. A sessão é o período de utilização iniciado depois da autenticação.

4. Sistemas operativos em modo texto e modo gráfico

⌨️ Modo texto

  • Comandos escritos
  • Automatização fácil
  • Baixo consumo de recursos
  • Exige conhecimento da sintaxe

🖱️ Modo gráfico

  • Janelas e menus
  • Mais intuitivo para iniciantes
  • Facilita tarefas visuais
  • Pode consumir mais recursos
📝 Tarefa 4 — Escolher o ambiente

Enunciado: Para administrar remotamente um servidor, qual ambiente pode ser particularmente útil?

Resolução exemplo: O modo texto/terminal é muito útil porque permite administrar o sistema através de SSH, executar comandos rapidamente e automatizar tarefas.

6. Gestão de ficheiros e diretórios através da linha de comandos

Caminho absoluto indica a localização completa. Caminho relativo parte da localização atual.

Exemplo: /home/aluno/documentos/trabalho.txt é um caminho absoluto. documentos/trabalho.txt pode ser relativo.
📝 Tarefa 6 — Copiar e pesquisar um ficheiro

Enunciado: Cria trabalho.txt, copia-o para backup e procura-o no diretório pessoal.

Resolução Linux:

touch trabalho.txt
mkdir backup
cp trabalho.txt backup/
find ~ -name "trabalho.txt"

📝 Tarefa 7 — Interpretar permissões

Enunciado: Interpreta -rw-r--r--.

Resolução: O proprietário pode ler e escrever; o grupo pode ler; os restantes utilizadores podem ler. Não existe permissão de execução.

Enunciado: Um computador está com pouco espaço em disco. Que comando podes usar primeiro?

Resolução: df -h permite consultar o espaço utilizado e disponível nos sistemas de ficheiros.

9. Instalação de um sistema operativo em modo texto

  1. Definir objetivo e requisitos.
  2. Escolher a distribuição/versão.
  3. Criar suporte de instalação.
  4. Configurar a máquina virtual ou computador.
  5. Instalar o sistema.
  6. Criar utilizador e palavra-passe.
  7. Configurar rede.
  8. Atualizar o sistema.
⚠️ Atenção: numa instalação real, operações de particionamento podem apagar dados. Em contexto escolar, recomenda-se uma máquina virtual.
📝 Tarefa 9 — Plano de instalação

Enunciado: Cria um plano de instalação de Ubuntu Server numa máquina virtual.

Resolução exemplo: Criar VM → definir RAM/CPU/disco → associar ISO → iniciar instalação → criar utilizador → configurar rede → atualizar pacotes → testar ligação.

10. Configuração inicial de um sistema operativo em modo texto

Depois da instalação, devem ser verificadas as definições essenciais.

  • Nome do computador/hostname
  • Utilizadores e palavras-passe
  • Configuração de rede
  • Data e hora
  • Atualizações
  • Software necessário
📝 Tarefa 10 — Atualizar e instalar software

Enunciado: Num Ubuntu/Debian, atualiza a lista de pacotes e instala o editor nano.

Resolução:

sudo apt update
sudo apt install nano

11. Sistemas operativos em modo gráfico

O ambiente gráfico disponibiliza uma interface visual para executar tarefas.

🪟 Janelas

Apresentam aplicações e documentos.

📁 Gestor de ficheiros

Permite navegar e organizar dados.

⚙️ Definições

Permitem configurar o sistema.

📌 Barra de tarefas

Facilita o acesso a aplicações e janelas.

📝 Tarefa 11 — Explorar o ambiente

Enunciado: Abre o gestor de ficheiros e identifica: diretório pessoal, barra de navegação, área de conteúdo e definições.

Resolução exemplo: O aluno deve indicar corretamente cada componente e explicar a sua função.

12. Gestão de ficheiros e aplicações em modo gráfico

As operações mais comuns são criar, copiar, mover, renomear e eliminar.

📝 Tarefa 12 — Organização de documentos

Enunciado: No ambiente gráfico, cria a pasta ProjetoSO com subpastas Documentos, Imagens e Backup. Cria um ficheiro de texto e copia-o para Backup.

Resolução exemplo: Criar pasta → abrir pasta → criar três subpastas → criar ficheiro em Documentos → selecionar ficheiro → Copiar → abrir Backup → Colar.

13. Instalação de um sistema operativo em modo gráfico

Uma instalação gráfica apresenta assistentes para idioma, teclado, disco, utilizador, rede e outras opções.

📝 Tarefa 13 — Sequência de instalação

Enunciado: Ordena: criar utilizador; selecionar idioma; particionar disco; configurar teclado; instalar ficheiros.

Resolução exemplo: Idioma → teclado → disco/partições → instalação dos ficheiros → criação/configuração do utilizador. A ordem exata pode variar conforme o instalador.

14. Configuração de um sistema operativo em modo gráfico

  • Rede Wi-Fi/Ethernet
  • Dispositivos e periféricos
  • Atualizações
  • Idioma e região
  • Data e hora

  • Personalização
📝 Tarefa 14 — Configurar uma máquina

Enunciado: Configura uma máquina para um novo utilizador: define idioma PT-PT, data/hora corretas, rede e atualizações.

Resolução exemplo: Abrir Definições → Região/Idioma → Data e hora → Rede → Atualizações → reiniciar se necessário → testar Internet.

15. Administração e manutenção em modo gráfico

As ferramentas gráficas permitem acompanhar processos, gerir utilizadores, armazenamento, atualizações e dispositivos.

📝 Tarefa 15 — Diagnóstico de desempenho

Enunciado: Um programa deixou de responder. Como podes verificar o problema?

Resolução exemplo: Abrir o Gestor de Tarefas/Monitor do Sistema, identificar o processo que não responde, verificar CPU/RAM e, se necessário, terminar a aplicação.

16. Segurança e administração de sistemas operativos

🔐 Contas

Utilizar palavras-passe fortes e evitar partilhar credenciais.

🔄 Atualizações

Manter o SO e aplicações atualizados.

💾 Backups

Manter cópias de segurança dos dados importantes.

🛡️ Proteção

Utilizar firewall, proteção contra malware e práticas seguras.

📝 Tarefa 16 — Plano de segurança

Enunciado: Cria cinco regras de segurança para um computador escolar.

Resolução exemplo: 1) Usar palavra-passe forte; 2) não partilhar credenciais; 3) atualizar o SO; 4) realizar backups; 5) não instalar software de fontes desconhecidas.

17. Consolidação e avaliação prática

Realiza a atividade final numa máquina virtual. O objetivo é demonstrar competências em modo texto e modo gráfico.

🏆 Desafio final

  1. Criar uma máquina virtual com um sistema operativo.
  2. Criar um utilizador normal.
  3. Identificar CPU, RAM e armazenamento.
  4. Criar a estrutura Projeto/Documentos/Backup.
  5. Criar e copiar um ficheiro.
  6. Consultar informação do sistema.
  7. Verificar o estado da rede.
  8. Atualizar o sistema.
  9. Aceder ao ambiente gráfico e repetir uma operação de gestão de ficheiros.
  10. Aplicar pelo menos três medidas de segurança.
